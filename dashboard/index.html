Welcome to Driver Routes

Plan each driver's day in four steps. Everything updates instantly.
  1. Set the day. Choose how many drivers, minutes per stop, average speed and the length of a working day.
  2. Place the depot. The black D on the map is the depot: where every driver starts. Drag it to move it.
  3. Choose what to visit. Search for a terminal or press Browse all to pick from a table. Or skip this and route whole parishes.
  4. Read the routes. Each driver gets a colour, a numbered list and one-tap navigation. Tap a stop to find it on the map.

What you'll see

D
Depot — the starting point. Draggable.
S
Start stop — appears when you start from a selected terminal instead of the depot.
3
Numbered pin — the 3rd stop on that driver's route. Each driver has their own colour.
OVER DAY
This route is longer than the working day. Add a driver or remove stops.
APPROX
The map pin is only approximate. Navigation links search by address, so they are still accurate.
REMOTE
A group is too far from the depot for a day trip.
